# Security Policy

## Supported Versions
Active development and security patches are prioritized on the `main` branch.

## Reporting a Vulnerability
If you discover a potential security vulnerability or sensitive data exposure issue:
1. Please do **NOT** open a public GitHub issue.
2. Contact the maintainer directly via email: `mtricaud.cetri@gmail.com`.
3. Provide a clear technical summary and reproduction steps.
4. We will review, remediate, and patch any confirmed issues promptly.
