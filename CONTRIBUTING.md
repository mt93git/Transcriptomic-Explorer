# Contributing Guidelines

We welcome community contributions, bug reports, and enhancements to this scientific research software repository.

## How to Contribute

1. **Reporting Issues:**
   - Please file bug reports or feature requests via GitHub Issues.
   - Include a minimal reproducible example (data sample, error traceback, R session info / environment).

2. **Pull Requests:**
   - Fork the repository and create a descriptive feature branch (`feature/your-addition` or `fix/issue-description`).
   - Adhere to consistent code formatting, namespace scoping, and documentation.
   - Verify that all automated test scripts in `/tests` pass without errors.
   - Submit a Pull Request detailing the scientific and computational rationale.

## Governance & Code of Conduct
Please maintain a constructive, respectful, and collaborative scientific discourse at all times.
